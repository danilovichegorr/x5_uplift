# Анализ эффективности маркетингового воздействия в RFM-сегментах клиентов

Репозиторий содержит Jupyter Notebook с расчётами к исследованию **«Анализ эффективности маркетингового воздействия в RFM-сегментах клиентов»** (Е. Ю. Данилович, 2026).

Цель работы — проверить, одинаков ли дополнительный эффект маркетинговой коммуникации для клиентов с разной покупательской активностью. Для этого RFM-сегментация совмещается с оценкой *uplift* — разницы в долях целевых покупок между экспериментальной и контрольной группами.

## Данные

Используется открытый датасет **X5 RetailHero Uplift Modeling**. В исследование включены **200 039 клиентов**.

Для запуска ноутбука нужны два файла:

- `uplift_train.csv` — идентификатор клиента (`client_id`), признак маркетингового воздействия (`treatment_flg`) и факт целевой покупки (`target`);
- `purchases.csv` — история покупок до воздействия, необходимая для расчёта Recency, Frequency и Monetary.

Файл `clients.csv` входит в исходный датасет, но в расчётах этого ноутбука не используется.

### Как скачать датасет

**Способ 1 — скачать исходные файлы.** Ссылки на архивы из источника, используемого библиотекой `scikit-uplift`:

1. [uplift_train.csv.gz](https://sklift.s3.eu-west-2.amazonaws.com/uplift_train.csv.gz)
2. [purchases.csv.gz](https://sklift.s3.eu-west-2.amazonaws.com/purchases.csv.gz)

Распакуйте оба `.gz`-архива. Файлы `uplift_train.csv` и `purchases.csv` поместите **в одну папку с `x5_rfm_analysis.ipynb`**: в ноутбуке указаны относительные пути к этим CSV.

**Способ 2 — через Python и `scikit-uplift`.**

```bash
pip install scikit-uplift
```

```python
from sklift.datasets import fetch_x5

dataset = fetch_x5()
```

Функция загружает набор данных и возвращает таблицы в `dataset.data` (`train`, `purchases`, `clients`), а также отдельно `dataset.target` и `dataset.treatment`. По умолчанию файлы сохраняются в кэше `~/scikit-uplift-data`, **а не рядом с ноутбуком**. Чтобы выполнить именно этот ноутбук без изменения кода, удобнее использовать первый способ: распаковать оригинальные CSV в рабочую папку. Кроме того, `fetch_x5()` загружает большие таблицы в память.

Подробнее о наборе данных: [документация `fetch_x5`](https://www.uplift-modeling.com/en/latest/api/datasets/fetch_x5.html) и [страница X5 RetailHero на ODS](https://ods.ai/competitions/x5-retailhero-uplift-modeling/data).

> `purchases.csv` — большой файл (десятки миллионов строк). Для повторного запуска расчётов потребуется достаточно свободного места и оперативной памяти. Крупные файлы исходных данных необязательно загружать в GitHub.

## Методика

В ноутбуке реализованы следующие этапы:

1. Проверка данных и объединение товарных строк в уникальные транзакции; большой файл покупок обрабатывается частями.
2. Расчёт RFM-признаков: **Recency** — давность последней покупки, **Frequency** — число транзакций, **Monetary** — суммарный объём покупок.
3. Присвоение каждому признаку оценки от 1 до 5 и формирование суммарного RFM-балла от 3 до 15.
4. Разделение клиентов на пять сегментов: низкая ценность (3–5), ниже средней (6–8), средняя (9–10), выше средней (11–13), высокая ценность (14–15).
5. Расчёт uplift в каждом сегменте как разницы долей покупок между экспериментальной и контрольной группами; построение 95%-ных доверительных интервалов методом Ньюкомба, z-тест для двух долей и поправка Холма на множественные сравнения.
6. Проверка изменения эффекта по уровням RFM с помощью линейной модели с взаимодействием между маркетинговым воздействием и порядковым уровнем сегмента (робастные стандартные ошибки HC3).

Здесь оценивается **средний дополнительный эффект внутри сегментов**, а не строится модель индивидуального uplift для каждого клиента.

## Основные результаты

| RFM-сегмент | Uplift, п. п. |
|---|---:|
| Низкая ценность | 4,62 |
| Ниже средней | 4,24 |
| Средняя | 3,95 |
| Выше средней | 1,91 |
| Высокая ценность | 0,88 |

Во всех пяти сегментах эффект положителен и остаётся статистически значимым после поправки Холма. При этом по мере роста RFM-ценности дополнительный прирост покупок снижается, хотя исходная доля покупающих клиентов становится выше.

Полученные результаты показывают, почему при выборе аудитории для маркетинговой кампании одной RFM-оценки может быть недостаточно. Для решения о запуске коммуникации также нужны данные о стоимости контакта, маржинальности и экономической отдаче — эти показатели в представленном анализе не рассчитывались.
